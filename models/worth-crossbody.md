## Lead

The Worth Crossbody (style 4143) is a Coach crossbody documented in
a single Tier 3 dealer compilation [yourgreatfinds-collectors-guide]
with minimal additional detail. Confidence is `tentative` until a
dated catalog scan or a second independent source corroborates the
style number, silhouette, and production era.

## Description

The Worth Crossbody is recorded only as a name-and-number entry in a
long Tier 3 collector list of vintage Coach styles
[yourgreatfinds-collectors-guide]. Silhouette specifics, dimensions,
available colors, and introduction year are unconfirmed in free
public sources.

**Style-number anomaly worth investigating.** Most Classic NYC-era
Coach styles in this list use a 9XXX numbering pattern (Willis 9927,
Court 9870, Wendi 9031, etc.). The Worth's `4143` is a four-digit
number that breaks the 9XXX convention, which suggests it may sit in
a different production era or product line than the bulk of NYC-era
crossbodies. Coach reused style numbers across decades and used
distinct numbering bands for sub-lines [coachbagrehab-dating], so the
4143 number alone does not pin the bag's era. A dated catalog match
is the priority verification item.

## Authentication

The era-keyed authentication matrix in `authentication/` covers the
full set of diagnostics. The era-anchoring features for the Worth
Crossbody specifically:

- **Style number 4143.** Visible on the leather creed on numbered-
  creed examples [yourgreatfinds-collectors-guide]. A style number
  alone does not date a specific bag — Coach reused style numbers
  across multiple production years.
- **Creed wording (E3 vs E4 diagnostic).** A pre-1994 Worth should
  read "COACH LEATHERWARE" with "LEATHERWARE" stamped in small
  letters beneath "COACH" [coachbagrehab-dating, vintagecoachie].
  Absence of "LEATHERWARE" places the bag in 1994 or later (E4).
- **Serial format.** Pre-1994 examples carry a digit-only unique
  serial; post-1994 examples use the
  `[A-M][year-digit][factory-letter]-4143` pattern with the
  documented single-digit-year ambiguity [coachbagrehab-dating]
  (`tentative`).
- **Hardware.** Solid brass, non-magnetic. A magnet that sticks
  indicates plated steel and is a strong reproduction signal
  [coachbagrehab-dating].
