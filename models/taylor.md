## Lead

The Taylor (style 9944) is a Coach Classic NYC-era model documented
in a single Tier 3 dealer compilation [yourgreatfinds-collectors-guide]
with minimal additional detail. Confidence is `tentative` until a
dated catalog scan or a second independent source corroborates the

## Description

Beyond the model name "Taylor" and style number 9944, the surviving
public record is sparse. Silhouette type, dimensions, available
colors, and introduction year are all unconfirmed. The bag is
recorded only as an entry in a long Tier 3 collector list of
NYC-era styles [yourgreatfinds-collectors-guide]; no images,
catalog appearances, or dimensional data have been located in free
public sources to date.

The 9944 style number sits in the dense 99XX band that includes
many other documented Classic NYC-era models (Willis 9927, Murphy
9930, Trail Bag 9965, Anderson 9976), which is consistent with — but
does not confirm — placement in the same E3 production window.

## Authentication

A pre-1994 Taylor should carry the diagnostics common to the
Classic NYC era (cross-reference `authentication/` for the full
era-keyed matrix):

- **Style number 9944.** Visible on the leather creed on numbered-
  creed examples [yourgreatfinds-collectors-guide]. A style number
  alone does not date a specific bag — Coach reused style numbers
  across multiple production years.
- **Creed wording (E3 diagnostic).** A pre-1994 Taylor should read
  "COACH LEATHERWARE" with "LEATHERWARE" stamped in small letters
  beneath "COACH," typically with "Made in United States" or
  "Made in New York City, U.S.A." on earlier examples
  [coachbagrehab-dating, vintagecoachie].
- **Serial format.** Pre-1994 examples carry a digit-only unique
  serial (`xxx-xxxx` 1970s, `xxxx-xxx` 1980s) per
  [coachbagrehab-dating] — `tentative`. Any post-1994 production
  carrying 9944 forward (E4) would use the
  `[A-M][year-digit][factory-letter]-9944` pattern with the
  documented single-digit-year ambiguity.
- **Hardware.** Solid brass, non-magnetic. A magnet that sticks
  indicates plated steel and is a strong reproduction signal
  [coachbagrehab-dating].
