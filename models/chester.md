## Lead

The Chester (style 9982) is a Coach Classic NYC-era model documented
in a single Tier 3 dealer compilation [yourgreatfinds-collectors-guide].
A smaller related variant — the "Canteen bag" — is noted in the
same source as very rare and hard to locate. Confidence is
`tentative` for the Chester itself; the Canteen variant relationship
is documented but unverified beyond the single source.

## Description

The model name "Chester" identifies an NYC-era Coach silhouette, but
specific form (satchel, shoulder bag, or other), dimensions, closure
type, lining, available colors, and introduction year are all
unconfirmed in free public sources beyond [yourgreatfinds-collectors-guide].

The same source describes a related smaller variant called the
**"Canteen bag"** — characterized as a smaller version of the
Chester silhouette and noted as very rare and difficult to locate
[yourgreatfinds-collectors-guide]. No separate style number for the
Canteen variant has been documented in free public sources, and no
images or dated catalog appearances have been located for either the
full-size Chester or the Canteen variant. The Chester/Canteen
relationship parallels other documented NYC-era full-size/mini
pairs (Willis 9927 and Winnie 9023; Court and Plaza/Bella) where a
named smaller variant tracks a parent silhouette.

## Authentication

A pre-1994 Chester (or Canteen variant) should carry the diagnostics
common to the Classic NYC era (cross-reference `authentication/` for
the full era-keyed matrix):

- **Style number 9982.** Visible on the leather creed inside the
  Chester on numbered-creed examples [yourgreatfinds-collectors-guide].
  The Canteen variant's style number is not documented in free
  public sources to date. A style number alone does not date a
  specific bag — Coach reused style numbers across multiple
  production years.
- **Creed wording (E3 diagnostic).** A pre-1994 example should read
  "COACH LEATHERWARE" with "LEATHERWARE" stamped in small letters
  beneath "COACH," typically with "Made in United States" or
  "Made in New York City, U.S.A." on earlier examples
  [coachbagrehab-dating, vintagecoachie].
- **Serial format.** Pre-1994 examples carry a digit-only unique
  serial (`xxx-xxxx` 1970s, `xxxx-xxx` 1980s) per
  [coachbagrehab-dating] — `tentative`. Any post-1994 production
  carrying 9982 forward (E4) would use the
  `[A-M][year-digit][factory-letter]-9982` pattern with the
  documented single-digit-year ambiguity.
- **Hardware.** Solid brass, non-magnetic. A magnet that sticks
  indicates plated steel and is a strong reproduction signal
  [coachbagrehab-dating].
