## Lead

The Avenue is a Coach Classic NYC-era model documented in a single
Tier 3 dealer compilation [yourgreatfinds-collectors-guide]. The same
source notes an "Avenue Shoulder Bag" variant. No style number is
recorded in free public sources. Confidence is `tentative` until a
dated catalog scan or a second independent source corroborates the
name, style number, and silhouette.

## Description

The Avenue is named on a long Tier 3 list of NYC-era styles
[yourgreatfinds-collectors-guide], with a noted **Avenue Shoulder
Bag** variant suggesting a shoulder-carry silhouette as one
configuration in the line. Dimensions, introduction year, and color
range are unconfirmed. Whether "Avenue" and "Avenue Shoulder Bag"
designate distinct style numbers or two names for the same bag is
itself unresolved in the surviving public record. No images, dated
catalog appearances, or dimensional data have been located in free
public sources to date.

## Authentication

A pre-1994 Avenue should carry the diagnostics common to the Classic
NYC era (cross-reference `authentication/` for the full era-keyed
matrix):

- **Creed wording (E3 diagnostic).** A pre-1994 Avenue should read
  "COACH LEATHERWARE" with "LEATHERWARE" stamped in small letters
  beneath "COACH," typically with "Made in United States" or "Made
  in New York City, U.S.A." on earlier examples
  [coachbagrehab-dating, vintagecoachie].
- **Serial format.** Pre-1994 examples carry a digit-only unique
  serial (`xxx-xxxx` 1970s, `xxxx-xxx` 1980s) per
  [coachbagrehab-dating] — `tentative`. Any post-1994 (E4)
  production would use the
  `[A-M][year-digit][factory-letter]-[style-number]` pattern with
  the documented single-digit-year ambiguity.
- **Hardware.** Solid brass, non-magnetic. A magnet that sticks
  indicates plated steel and is a strong reproduction signal
  [coachbagrehab-dating].
- **Variant disambiguation.** When evaluating a bag tagged
  "Avenue," confirm whether the seller is describing the base
  Avenue or the Avenue Shoulder Bag variant
  [yourgreatfinds-collectors-guide]; the variant distinction is
  not yet resolvable from free public data.
