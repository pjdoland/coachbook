## Lead

The Trail Bag (style 9965) is a Coach Classic NYC-era cross-body
model documented in a Tier 3 dealer compilation
[yourgreatfinds-collectors-guide]. The same style number is also
recorded for a "9965 Black Trail Crossbody Bag" variant, indicating
a trail-specific cross-body configuration carried under one style
number across at least one documented colorway.

## Description

The Trail Bag is identified as a cross-body silhouette under style
number 9965 [yourgreatfinds-collectors-guide]. The
"Black Trail Crossbody Bag" listing under the same number confirms
black as a documented color and the cross-body strap configuration
as the canonical form. Beyond color and cross-body strap type,
silhouette dimensions, lining details, and introduction year are
unconfirmed in free public sources.

## Authentication

A pre-1994 Trail Bag should carry the diagnostics common to the
Classic NYC era (cross-reference `authentication/` for the full
era-keyed matrix):

- **Style number 9965.** Visible on the leather creed inside the
  bag on numbered-creed examples [yourgreatfinds-collectors-guide].
  A style number alone does not date a specific bag — Coach reused
  style numbers across multiple production years.
- **Creed wording (E3 diagnostic).** A pre-1994 Trail Bag should
  read "COACH LEATHERWARE" with "LEATHERWARE" stamped in small
  letters beneath "COACH," typically with "Made in United States"
  or "Made in New York City, U.S.A." on earlier examples
  [coachbagrehab-dating, vintagecoachie].
- **Serial format.** Pre-1994 examples carry a digit-only unique
  serial (`xxx-xxxx` 1970s, `xxxx-xxx` 1980s) per
  [coachbagrehab-dating] — `tentative`. Any post-1994 production
  carrying 9965 forward (E4) would use the
  `[A-M][year-digit][factory-letter]-9965` pattern with the
  documented single-digit-year ambiguity.
- **Hardware.** Solid brass cross-body strap fittings,
  non-magnetic. A magnet that sticks indicates plated steel and is
  a strong reproduction signal [coachbagrehab-dating].
