# Murphy

## Lead

Murphy (style 9930) is a Coach NYC-era handbag described in the
dealer-compiled record as resembling the Willis silhouette but **without
the shoulder strap handle** [yourgreatfinds-collectors-guide]. It is a
companion model to Willis (9927) rather than a variant.

## Description

Per the dealer record, Murphy uses the front-flap-with-turnlock
construction associated with Willis but is built without a strap, making
it a hand-carry rather than a crossbody. The original retail price is
recorded as $198.00 in a single dealer source — useful as an era anchor
(consistent with mid-to-late NYC-era Coach pricing) but not as a
production-date indicator.

## Designer

In-house, post-Cashin (Cashin's contract ended 1974; Willis-family
silhouettes are 1980s onward). Murphy is **not** a Cashin design — see
the over-attribution discussion in
[designers/bonnie-cashin.md](../designers/bonnie-cashin.md).

## Authentication

- **Style number**: 9930 in the creed [yourgreatfinds-collectors-guide]
- **Era diagnostics**: same as Willis — pre-1994 examples carry the
  small-caps "LEATHERWARE" wordmark beneath "COACH"; post-1994
  examples use the letter-digit-letter style code (subject to the
  single-digit-year ambiguity flagged in
  [authentication/serial-numbers.md](../authentication/serial-numbers.md))
  [coachbagrehab-dating]
- **Hardware**: solid brass turnlock (magnet test); brass dogleash
  hardware not applicable since Murphy lacks a removable strap
- **Edges**: raw or burnished, never painted [vintagecoachie]
- **Folklore guard**: any "Murphy" attribution to Cashin is wrong by
  era

## Open verification items

1. Introduction year — research/D-models.md does not anchor Murphy to a
   specific year. A 1980s or early-1990s catalog page showing 9930
   would settle this.
2. Dimensions — not in the working research. Murphy is described
   relative to Willis but the size relationship is unstated.
3. Color list — not in the working research.
4. Why "Murphy"? — the bag-naming convention at NYC-era Coach was
   geographic and family names; "Murphy" fits but the specific origin
   is undocumented.
