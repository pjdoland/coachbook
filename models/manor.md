## Lead

The Manor is a Coach Classic NYC-era model documented in a single
Tier 3 dealer compilation [yourgreatfinds-collectors-guide] by name
only, with no style number, dimensions, or introduction year
recorded. Confidence is `tentative` until a dated catalog scan or a
second independent source corroborates the model.

## Description

Beyond the model name "Manor," the surviving public record is
sparse. Silhouette type, style number, dimensions, available
colors, and introduction year are all unconfirmed. The bag is
recorded only as an entry on a long Tier 3 collector list of
NYC-era styles [yourgreatfinds-collectors-guide]; no images, dated
catalog appearances, or dimensional data have been located in free
public sources to date.

## Authentication

A pre-1994 Manor should carry the diagnostics common to the
Classic NYC era (cross-reference `authentication/` for the full
era-keyed matrix):

- **Creed wording (E3 diagnostic).** A pre-1994 Manor should read
  "COACH LEATHERWARE" with "LEATHERWARE" stamped in small letters
  beneath "COACH," typically with "Made in United States" or "Made
  in New York City, U.S.A." on earlier examples
  [coachbagrehab-dating, vintagecoachie].
- **Serial format.** Pre-1994 examples carry a digit-only unique
  serial (`xxx-xxxx` 1970s, `xxxx-xxx` 1980s) per
  [coachbagrehab-dating] — `tentative`. Any post-1994 (E4)
  production would use the
  `[A-M][year-digit][factory-letter]-[style-number]` pattern with
  the documented single-digit-year ambiguity.
- **Hardware.** Solid brass, non-magnetic. A magnet that sticks
  indicates plated steel and is a strong reproduction signal
  [coachbagrehab-dating].
