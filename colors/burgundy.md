# Burgundy

## Lead

Burgundy is a deep wine-red Coach color appearing across multiple
NYC-era and transition-era models [yourgreatfinds-collectors-guide,
vintagecoachie]. Some catalog and dealer references use **Bordeaux**
for what appears to be the same or an adjacent dark red Coach color;
whether Burgundy and Bordeaux are two names for one color, two distinct
colorways, or successive era-specific names is currently unresolved.
Where both names appear in this archive, they should be distinguished
by the documenting source rather than collapsed.

## Description

Burgundy reads as a deep, muted wine red on glove-tanned cowhide —
darker than oxblood, less brown than mahogany, with cooler purple-red
undertones. Because Coach's NYC-era leather was drum-dyed through (the
cut edge shows the same color as the surface — see
[authentication/leather.md](../authentication/leather.md)), Burgundy
develops darker mahogany-leaning undertones with patina rather than
fading or rubbing off. Worn examples typically deepen toward
near-black-red at high-handling points (handles, corners, flap edges).

The color name has been Coach's own usage; non-Coach "burgundy"
leathers should not be assumed to match.

## Models documented in Burgundy

The Phase 0 model canon (`research/D-models.md`) does not surface
Burgundy on a specific style number. Burgundy is referenced in the
British Tan entry as one of the most-recognized Coach color names
alongside Black and Mahogany, but per-model Burgundy documentation
remains to be compiled from catalog scans and dealer listings
[yourgreatfinds-collectors-guide].

This list is open and should be expanded as catalog scans, dealer
listings, and forum-documented examples are added.

## Authentication

- Burgundy is a Coach color name, not a generic descriptor — a listing
  description that says "wine," "maroon," or "dark red" should be
  matched to a specific Coach color name before being treated as
  Burgundy
- Drum-dyed-through is a leather authenticity signal, not a color
  signal: a Burgundy bag should still pass the standard edge-color
  check (see authentication/leather.md), with the cut edge reading
  the same deep wine red as the surface
- Reproductions and counterfeits sometimes match the surface color
  approximately while missing the cool undertone or showing
  contrasting under-color at scuffs; authentic Burgundy should darken
  with handling, not lighten or fade pink

## Era anchoring

Burgundy appears across multiple Coach eras (NYC era through the
transition era and into Coach Originals re-releases). It is not useful
as an era anchor on its own: the same color name persists across
decades, so Burgundy alone does not date a bag. Combine with creed
wording, serial format, hardware, and country-of-origin (see
[authentication/](../authentication/)) for era placement.

## Open verification items

1. **Burgundy vs Bordeaux** — are these one color under two names, two
   distinct colorways, or successive era-specific names for the same
   shade? Catalog scans showing one or both names against a dated page
   would settle this. Currently `tentative`.
2. **Catalog-anchored color introduction date** — when did "Burgundy"
   first appear as a Coach color name? An early NYC-era catalog page
   would settle this.
3. **Decade-specific formula differences** — community sources
   occasionally note that dark-red Coach leathers look different
   across decades (pre-1985 Sara Lee era vs post-1985, Costa Rican
   leather vs U.S.-tanned). No primary source confirms a formula
   change; flag for inspection of dated examples.
4. **Per-model Burgundy documentation** — populate the "Models
   documented in Burgundy" section as dealer listings and catalog
   scans surface specific style numbers in this color.
